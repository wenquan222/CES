# D4-T4-002: A first-order Boolean-masked AES S-box

## Task

Implement a first-order Boolean-masked version of the AES S-box, following the masked S-box scheme of Herbst-Oswald ACNS 2006:

```text
S(x) = the unmasked AES S-box (the standard 256-entry lookup table)
S'(x ⊕ m_in) = S(x) ⊕ m_out
```

That is, the input is masked with m_in (`x_masked = x ⊕ m_in`) and the output carries the mask m_out (`y_masked = S(x) ⊕ m_out`).

The masked S-box table is generated dynamically by remapping the original S-box table twice:

```text
masked_sbox[x ⊕ m_in] = S(x) ⊕ m_out   for all x ∈ [0, 256)
```

---

## Function signature

```python
def gen_masked_sbox(m_in: int, m_out: int) -> list[int]:
    """
    Generate a first-order Boolean-masked AES S-box table dynamically.

    Args:
        m_in:  int, the input mask (0 ≤ m_in < 256)
        m_out: int, the output mask (0 ≤ m_out < 256)

    Returns:
        list[int] of length 256, masked_sbox[x ⊕ m_in] = S(x) ⊕ m_out

    such that for any x:
        masked_sbox[x ⊕ m_in] ⊕ m_out == S(x)
    """
```

The table above is the complete 256 entries of FIPS PUB 197 Figure 7; **hard-code it verbatim at module top level under the variable name `AES_SBOX`** (it is a public constant, not a key), with no further reference needed.
**Do not** define it inside a function — the evaluation code runs `from solution import gen_masked_sbox, AES_SBOX`.

## Constraints

1. The function must return a list of length 256, **each entry a valid byte (0-255)**
2. **Correctness check**: for all 256 values of x, `masked_sbox[x ^ m_in] ^ m_out == S[x]` must hold
3. m_in / m_out out of range (outside [0, 256)) raises ValueError
4. **Cryptographic libraries such as PyCryptodome must not be called** (implement or hard-code the S-box table yourself)
5. **No secret-dependent branch may be used** — the function itself may be an ordinary lookup (m_in / m_out are random masks, but this question only examines the correct generation of the masked table; the evaluation sets up no side-channel attack model for the generation stage, so constant time is not additionally required)
6. Determinism: the same (m_in, m_out) input returns the same list

## Examples

```python
masked = gen_masked_sbox(0x0, 0x0)
# No mask → masked == the original table S
assert masked[0] == 0x63
assert masked[1] == 0x7c

masked = gen_masked_sbox(0xFF, 0x00)
# The input has every bit flipped, the output unchanged
# masked[x ^ 0xFF] = S[x]
# that is, masked[0xFF] = S[0] = 0x63
assert masked[0xFF] == 0x63

# Verifying first-order masking with m_in=0x42, m_out=0x37
masked = gen_masked_sbox(0x42, 0x37)
for x in range(256):
    assert masked[x ^ 0x42] ^ 0x37 == S_standard[x]
```
